# 🎓 Smart Learning Platform

A full-stack learning platform where students can register, login, browse courses and attempt quizzes.

---

## 🚀 Features
- 🔐 Register & Login
- 📚 Browse Courses
- 📝 MCQ Quiz with Score

---

## 🛠️ Tech Stack
- **Backend:** Spring Boot (Java)
- **Frontend:** React.js
- **Database:** MySQL
- **Tools:** XAMPP, VS Code, Git

---

## ⚙️ How to Run

**1. Start XAMPP** — Start Apache + MySQL

**2. Run Backend**
```bash
./mvnw spring-boot:run
```

**3. Run Frontend**
```bash
cd frontend
npm install
npm start
```

**4. Open Browser**
```
http://localhost:3000
```

---

## 📡 APIs
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/register` | Register user |
| POST | `/api/login` | Login user |
| GET | `/api/courses` | Get courses |
| GET | `/api/quiz` | Get quiz |
| POST | `/api/quiz/submit` | Submit quiz |
